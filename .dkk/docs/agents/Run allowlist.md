## Summary

The subset of its agent's tools a run is offered, named by the service that starts it (a design run names the story, one kind's existing assets and that kind's save, so it cannot save another kind). A run without one is offered the agent's whole set for its scope. Every allowlist a service names is checked against the agent's tools at boot, and one naming a tool the agent lacks is refused (adr-0024).
