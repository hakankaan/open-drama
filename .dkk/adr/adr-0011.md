# ADR-0011 — English is the canonical language for prompts, skills, UI and content

## Context

Much of the AI short-drama audience works in Chinese, which argues for Chinese-first texts (prompts, skills, agent messages, shot markers). Open Drama is an international open project and its canonical texts must be readable by all contributors.

## Decision

- **English is canonical** for agent prompts, skills, agent user messages, UI message catalogs, shot markers (`[Shot N]`) and default content language.
- `zh`, `ja`, `ko` are **variants**: `prompts/<agent>.<lang>.md`, `SKILL.<lang>.md`, `messages/<lang>.json`, falling back to English when missing.
- The UI language and the AI content language are **one setting** switched together, stored in `app_settings.contentLanguage` and mirrored in the browser.
- The language directive (highest priority, never translate existing `@mentioned` asset names, style prefix is injected by the system) is appended for any content language other than English.

## Alternatives Considered

- **Chinese canonical with an English directive.** Rejected: contributors cannot review what the agents are told.
- **Separate UI and content language settings.** Rejected for now: a single switch is simpler for creators; splitting later is a small change.

## Consequences

- All canonical texts in this repository are English and written here (`adr-0001`).
- Chinese users get parity through variants that must be maintained; missing variants degrade to English gracefully.
